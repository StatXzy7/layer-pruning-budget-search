# 跨层结构剪枝预算搜索器（Linux CPU，纯 Java 标准库）

为小型前馈残差网络逐层选择一个离散裁剪候选，在“总真实保留参数数 ≤ 预算”
的约束下降低端到端校准 MSE。每个被计费的评估都会把所选候选矩阵**真实组合
成完整网络并执行**，不累加任何逐层局部误差。

## 构建与测试

```bash
./verify.sh
```

脚本仅依赖 JDK（`javac`/`java`），编译 `src/` 与 `test/` 后运行零依赖测试
框架；测试失败或**零测试用例**时以非零状态退出。

## 核心类型（`src/prune`）

- `Activation` / `LayerSpec` / `NetworkConfig`：前馈残差网络。层
  `i` 计算 `act(W_i·a_{i-1}+b_i)`，可配置残差来源层（必须更早且输出维相同），
  相邻层维度必须可组合。
- `Candidate`：单层候选——已裁剪并补偿的权重矩阵、**真实保留参数数**、
  裁剪等级（等级越大裁剪越粗），维度与原层一致。
- `PruningProblem`：原网络、逐层候选、校准输入、参考输出、参数预算。
  空候选层、维度错误、负参数数、非有限矩阵、不可组合残差等一律抛
  `InvalidProblemException`；负预算抛 `IllegalArgumentException`。
- `NetworkRunner`：CPU 端到端执行与均值平方误差。
- `PruningSearcher.run(seed, maxEvaluations)`：固定种子、有限次数搜索。
- `SearchResult`：各层选择（候选序号与等级）、总参数数、误差、实际评估
  次数、可行方案数、状态与可读 `report()`。

## 搜索策略与计费规则

1. 每层候选按“保留参数升序（裁剪等级降序、原序号次序）”排序，先探粗裁剪；
   最粗可行组合为起点。
2. 仅朝更细候选做坐标式爬山，并在粗裁剪可行区域做带偏随机重启（固定种子
   完全可复现）。
3. 评估额度允许时，按参数和剪枝穷举所有可行组合，此时返回
   `PROVEN_OPTIMAL`；额度耗尽则返回当前最佳可行结果 `CAP_REACHED`，
   报告中明确标注“非全局最优”。
4. **组合矩阵完全相同的方案（即使来自不同重复候选）直接命中缓存，不扣评估
   额度。**
5. 误差并列时按逐层候选序号序列选字典序最小者，结果稳定、与种子无关。
6. 任何可行组合都不存在时返回 `INFEASIBLE`（0 次执行）；预算等于可行下限
   与极紧预算均有对应测试。

## 测试覆盖（`test/prune/Tests.java`）

- 报告误差与独立直接执行一致；含/不含残差两套小网络均与独立穷举参考
  零差距，并打印穷举最优与差距。
- 逐层局部代理最优 ≠ 组合最优的夹具上，搜索仍命中穷举最优。
- 预算守恒、等于预算下限、极紧预算、零预算。
- 固定种子逐位复现；评估上限精确停机并保留已有最佳。
- 重复候选不重复计费；并列按层选择序列稳定。
- 空候选层、错误维度、负参数数、非有限矩阵、残差不可组合等非法输入。
